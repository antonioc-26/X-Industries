# 🚀 X-Industries

X-Industries is a web-based e-commerce application originally developed as a team project and later migrated from CodeSandbox to GitHub for continued development as a personal project.

This repository now serves as the foundation for future improvements, refactoring, and feature expansion.

---

## ✨ Features

- 🛍️ Product browsing by category
- 🔍 Search functionality
- 🛒 Shopping cart system
- ⚡ Buy Now flow
- 👤 User authentication (login/register)
- 📦 Orders tracking
- 📊 User dashboard & profile

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, Vanilla JavaScript  
- **Backend:** Node.js  
- **Data:** JSON (local/mock data)

## ⚙️ Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/your-username/x-industries.git
cd x-industries
```
2. Install dependencies:
```
npm install
```
Run the server:
```
node index.js
```
Open in browser:
```
http://localhost:3000
```
